# v2.4.3 - Sicherheit & Wartung

**Veröffentlicht:** 25.11.2026

## Sicherheit
- Abhängigkeiten mit bekannten Sicherheitslücken aktualisiert (ASP.NET Core 10.0.15, MailKit, MySqlConnector, JWT-Bibliotheken)
- Bildverarbeitung von ImageSharp auf SkiaSharp umgestellt – hochgeladene Bilder werden nicht mehr von einer Bibliothek mit offenen Sicherheitsmeldungen verarbeitet
- Docker: Der Container läuft als unprivilegierter Benutzer und der Datenbank-Port wird standardmäßig nicht mehr nach außen freigegeben

## Verbesserungen
- Ungültige Bild-Uploads liefern eine verständliche Fehlermeldung statt eines Serverfehlers
- Unbekannte API-Routen liefern 404 statt der Web-App
- Die Synchronisation mit der Open Filament Database nutzt HTTPS
- Das Docker-Image basiert auf den stabilen .NET-10-Images
- Deployments tauschen Releases atomar und rollen automatisch zurück, wenn die neue Version nicht startet

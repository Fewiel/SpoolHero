# v2.0.0 - Open Filament Database & Orca Slicer Export

**Veröffentlicht:** 10.04.2026

## Neue Features
- **Open Filament Database**: Über 14.000 Filament-Materialien aus der Community-gepflegten OFD synchronisieren
- **Orca Slicer Export**: Filament-Profile als Orca/Snapmaker Orca kompatible JSON-Dateien exportieren
- **Community Vorschläge**: Nutzer können Materialverbesserungen einreichen, Admins prüfen und genehmigen
- **Material Picker**: Durchsuchbares Dropdown mit Farbvorschau, Marke, Typ und Temperatur
- **Admin Vorschläge-Seite**: Community-Vorschläge prüfen, genehmigen oder ablehnen

## Verbesserungen
- Clientseitige Suche und Pagination (50 Einträge pro Seite) für Materiallisten
- Materiallisten laden nach erstem Abruf sofort
- Neuer Navigationseintrag für Orca Export
- Temperaturwarnung beim Export von Materialien mit fehlenden Daten (0 Grad)

# v2.3.0 - Passwort vergessen & Aktivierungslink erneut senden

**Veröffentlicht:** 12.04.2026

## Neue Features
- **Passwort vergessen**: Passwort per E-Mail-Link von der Login-Seite zurücksetzen
- **Passwort-Reset-Seite**: Neues Passwort setzen über den per E-Mail erhaltenen Link (1 Stunde gültig)
- **Aktivierungslink erneut senden**: Neuen Aktivierungslink auf der Verifizierungsseite anfordern wenn der Token abgelaufen ist

## Sicherheit
- Rate-Limiting für Passwort-Reset-Anfragen pro IP (5 Versuche, dann 15 Min Sperre)
- Rate-Limiting für Reset-Token-Versuche pro IP gegen Brute-Force
- E-Mail-Cooldown: maximal 1 Reset-E-Mail pro 2 Minuten pro Konto gegen E-Mail-Bombing
- Cooldown beim erneuten Senden des Aktivierungslinks gegen Spam
- Passwort-Reset macht alle bestehenden Sitzungen ungültig
- Keine Benutzer-Aufzählung: Passwort-Vergessen gibt immer die gleiche Antwort

# v2.5.1 - MySQL-8-Fix

**Veröffentlicht:** 25.11.2026

## Fehlerbehebungen
- Die Datenbank-Migration für Webhooks schlug unter MySQL 8 wegen eines unterschiedlichen Zeichensatzes zur Projekttabelle fehl. Die Migration übernimmt jetzt den passenden Zeichensatz und repariert auch eine halb angelegte Tabelle aus einem fehlgeschlagenen Versuch.

## Verbesserungen
- Jeder Pull Request startet SpoolHero jetzt gegen MySQL 8, damit alle Datenbank-Migrationen vor einem Release geprüft sind.

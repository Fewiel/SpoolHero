# v2.4.3 - Security & Maintenance

**Release Date:** 2026-11-25

## Security
- Updated dependencies with known vulnerabilities (ASP.NET Core 10.0.15, MailKit, MySqlConnector, JWT libraries)
- Image processing switched from ImageSharp to SkiaSharp – uploaded images are no longer decoded by a library with open security advisories
- Docker: the container runs as an unprivileged user and the database port is no longer published to the host by default

## Improvements
- Invalid image uploads return a clear error instead of a server error
- Unknown API routes return 404 instead of the web app
- Open Filament Database sync uses HTTPS
- Docker image is built from the stable .NET 10 images
- Deployments switch releases atomically and roll back automatically if the new version does not start

# v2.5.0 - Klipper, Webhooks & Community Wishes

**Release Date:** 2026-11-25

## New Features
- **Klipper / Moonraker (Spoolman API)**: SpoolHero now speaks the Spoolman API. Create an API key under Project Settings → Klipper / Moonraker and point `[spoolman]` in your moonraker.conf to SpoolHero – used filament is booked automatically. Other Spoolman clients (nfc2klipper, SpoolPainter, …) work too. NFC tags additionally carry the Spoolman spool id
- **Webhooks**: Send "dryer finished", "spool low" and "spool consumed" events to Discord, Telegram, Home Assistant or any JSON endpoint – with test button and delivery status
- **Spool owners**: Assign an owner to each spool, filter and search by owner – ideal when several people share one printer
- **Weigh spools**: Enter what your scale shows – the remaining filament is calculated from the empty spool weight (per material or per spool)
- **Stock by material**: New "By material" view in the spool list and a "Stock by material" section on the dashboard with the total weight of all spools of a material
- **Find spool via NFC**: Scan the tags on your shelf – SpoolHero tells you when you are holding the right spool
- **Clone materials**: Copy any material as a starting point for new colors or variants
- **Import OpenSpool .bin files**: Import tag files from the OpenSpool website when creating a spool – no NFC phone needed
- **Proxmox LXC & install script**: One command creates a SpoolHero container on Proxmox VE; `deploy/install.sh` installs SpoolHero on Debian/Ubuntu including updates with automatic rollback

## Improvements
- Spools in a dryer always show the dryer in the spool list
- NFC tag parsing understands full tag dumps and multi-record tags
- Deleting a project works again
- SQL statements (including sensitive parameters) are no longer written to the log
